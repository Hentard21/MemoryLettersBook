# Общие фотографии вводного блока

Исходные изображения, извлечённые из PDF без скриншотов страниц, лежат в:

`assets/intro-people/shared-events/for-gigapixel/`

Папка для результатов ручного апскейла:

`assets/intro-people/shared-events/ProUpscale/`

Правила:

- не перезаписывать `source-native/` и файлы с суффиксом `_source`;
- сохранять исходный кадр, лица, форму, награды и предметы;
- не удалять фон: это архивные, а не флагманские изображения;
- результат класть в `ProUpscale/` с тем же stem и суффиксом `_upscaled`;
- перед подстановкой в макет сверять изображение с `assets/intro-people/intro-reference-assets.json`.
