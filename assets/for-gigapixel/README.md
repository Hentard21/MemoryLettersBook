# Gigapixel staging

Эта папка предназначена только для следующей ручной партии.

- `flagship/<hero_id>/` — выбранный главный кадр героя;
- `archive/<hero_id>/` — поддерживающие семейные фотографии;
- `drawings/<hero_id>/` — рисунки, которым действительно нужен апскейл.

Завершённая партия от 19 июля 2026 года принята в
`assets/production-ready/` и перемещена без удаления в
`project-reset/archived/duplicate-assets/for-gigapixel-completed-2026-07-19/`.

Не помещать сюда рукописи и не запускать повторную массовую обработку без
нового явного решения: для печати уже зарегистрирован 281 результат.
