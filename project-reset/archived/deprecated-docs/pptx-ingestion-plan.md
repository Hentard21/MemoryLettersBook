# План приёма PPTX (когда придёт оригинальный PowerPoint)

> ## ⛔ ДОКУМЕНТ УСТАРЕЛ (2026-07-16)
> Оригинальные материалы (PPTX) **утеряны безвозвратно** — приёма не будет. `source/reference.pdf` окончательно становится единственным источником. Этот файл оставлен как исторический (описывает подход, который мог бы применяться). Актуальное — в `docs/AI_HANDOFF.md`, баннер вверху. Путь к печатному качеству изображений теперь — upscale нативных мастеров, а не замена оригиналами.

Цель (не будет достигнута — PPTX утерян): заменить данные `pdf_reference` полноценными исходниками, **не потеряв** классификацию, манифест и ручные пометки.

## Слои данных (что чем перезаписывается)

| Слой | Источник | При приёме PPTX |
|---|---|---|
| Извлечённые тексты/ассеты | скрипты по PDF | **Заменяются** данными из PPTX |
| Классификация страниц/архетипы | скрипты + визуальная разметка | **Сохраняется**, только проверяется |
| Ручные поля `manual_*`, `review_*`, редакционные поля (`edited_text`, `edit_*`, `approved_*`, расшифровки писем, `editorial_notes`) и журнал `editorial-changelog.json` | человек / редакционный процесс | **Никогда не перезаписываются автоматически** |
| id сущностей | конвейер | **Неизменны** — меняется только `source_ref` и `source_quality` |

## Шаг 1. Инвентаризация PPTX

- Положить файл в `source/` (например `source/book-original.pptx`), не переименовывая исходный PDF.
- Скриптом (python-pptx) снять: число слайдов, размер, список фигур/картинок/текстбоксов по слайдам → `workspace/reports/pptx-inventory.json`.

## Шаг 2. Сопоставление слайдов и страниц PDF

- Базовая гипотеза: контрольный PDF экспортирован из этого же PPTX (метаданные PDF: PowerPoint, 07.07.2026), значит **слайд N == страница N** (255/255).
- Проверка: (а) совпадение количества; (б) сверка текстов титулов героев слайда N с `page_NNN.txt`; (в) выборочная визуальная сверка рендеров.
- Расхождения (вставленные/удалённые слайды) решаются якорями — титулы героев уникальны (кроме известных плейсхолдеров) → выравнивание последовательностей по якорям, разрывы помечаются `REVIEW_REQUIRED`.
- Результат: `content/manifests/pdf-pptx-mapping.json` (`{pdf_page, pptx_slide, match_confidence}`).

## Шаг 3. Извлечение оригинальных изображений

- Из PPTX картинки достаются в исходном качестве (это zip: `ppt/media/*`), без пережатия экспорта в PDF.
- Каждое изображение: `workspace/extracted-assets/pptx/slide_NNN/img_KK.<ext>` + hash, размеры в px, dpi в конечном размере на слайде.
- Привязка к сущностям Photo/Drawing/Letter по слайду и позиции фигуры (координаты из XML слайда ≈ позиции в PDF).
- Флаг качества печати: `print_ready: dpi >= 250` в конечном размере полосы.

## Шаг 4. Обновление контентных сущностей

- Тексты: у каждого DocumentFragment/Person перечитать текст из текстбоксов слайда; при расхождении с PDF-версией — не затирать, а записать обе (`text_pdf`, `text_pptx`) + `REVIEW_REQUIRED`; после подтверждения человеком `text_pptx` становится каноном, `source_quality: "pptx_original"`.
- Плейсхолдеры (стр. 106, 139, 178, 186, 189, 213, 216 «НАШ ОТЕЦ ВЯЧЕСЛАВ…») — первоочередная проверка: в PPTX видно, реальный это текст или неисправленный шаблонный текстбокс.
- Ассеты: `scan_asset`/`asset` перенаправить на оригиналы из PPTX; PDF-вырезки остаются в архиве как fallback.
- Скрытые слайды/заметки докладчика из PPTX — зафиксировать отдельно (могут содержать полные ФИО героев и подписи — ценные метаданные).

## Шаг 5. Сохранение проделанной работы

- Перегенерация реестров выполняется merge-скриптом: новые данные вливаются в существующие записи по id; поля `manual_*`, `review_*`, редакционные поля (`edited_text`, `edit_*`, `approved_*`, расшифровки) и записи changelog копируются как есть. PPTX обновляет только `source_text`/`source_ref`/ассеты; утверждённые правки не сбрасываются, но при изменении `source_text` статус понижается до `approval_required` с пометкой «источник изменился».
- До приёма сделать снапшот: `workspace/reports/pre-pptx-snapshot/` (копия `content/`).
- После приёма — отчёт различий `workspace/reports/pptx-diff.md`: какие тексты изменились, какие ассеты заменены, какие REVIEW закрыты/открыты.

## Критерий готовности

- 100% страниц имеют сопоставленный слайд (или объяснённое расхождение).
- Все Photo/Drawing/Letter ссылаются на оригинальные ассеты с оценкой печатной пригодности.
- Список REVIEW_REQUIRED пересмотрен: плейсхолдеры и дубли закрыты решением человека.
- Везде, где данные взяты из PPTX, проставлено `source_quality: "pptx_original"`.
