# План project skill `letters-memory-book`

Skill автоматически не создавался. Этот документ задаёт его будущий контракт.

## Назначение

Skill должен включаться при работе с контентом, семейными блоками, картами, гербами, портретами и печатными прототипами книги. Его задача — не придумывать дизайн, а удерживать факты, порядок, воспроизводимость и проверки.

## Неизменяемые правила

1. Порядок семей берётся из утверждённого референса и `content/manifests/reference-first-20-map.json`; перестановка без явного решения владельца запрещена.
2. Материалы одной семьи не смешиваются с другой. Неоднозначность получает `REVIEW_REQUIRED`.
3. Блок героя состоит из двух разворотов:
   - ознакомительный: награда, имя, дети, регион/город, герб, корректно выделенный регион, флагманский портрет, одна цитата;
   - полный манифест: оригинальный текст целиком, без сокращения и тематических карточек, плюс 2–4 связанных материала.
4. Авторская орфография манифеста сохраняется. Синтетический текст и имитация официальной цитаты запрещены.
5. Инструменты навигации и OCR не являются источником фактов.

## Проверка региона, карты и герба

- сверить `hero_id` с `content/regions/regions.json`;
- проверить `official_name`, `region_code`, `map_feature_id`, город и `emblem_file`;
- регион на карте должен совпадать с кодом и подписью;
- герб только официальный/достоверно извлечённый, не нейросетевой;
- награда не подменяется гербом или декоративным знаком;
- сомнение блокирует публикацию и создаёт `REVIEW_REQUIRED`.

## Правила флагманских фотографий

- одна `hero_flagship` на ознакомительный разворот;
- сначала проверить native master и запись в `flagship-images.json`/asset manifests;
- по умолчанию: upscale и мягкая коррекция;
- удаление фона только при композиционной необходимости;
- генеративное достраивание только для обрезанных краёв тела/одежды, без изменения лица, одежды, предметов, нашивок и наград;
- все производные сохраняют связь с master и статус `derived`.

## Команды, которые skill должен знать

- Graphify build/query: `docs/COMMANDS.md`;
- HTML → PDF: `scripts/render_print_prototype.mjs`;
- Playwright screenshot и DOM-check: `docs/COMMANDS.md`;
- Poppler/PDF skill checks: `docs/COMMANDS.md`;
- JSON validation и smoke tests: `docs/COMMANDS.md`.

Skill не должен автоматически запускать массовую обработку изображений, OpenRouter, Gigapixel, рендер всей книги или перезапись master-файлов.

## Визуальный checklist

- утверждённая обложка и порядок страниц не изменены без задания;
- внутренний фон нейтральный молочный/серо-кремовый, без жёлтой старой бумаги;
- портрет не закрывает лицо текстом;
- крупные и малые фотографии сбалансированы по роли, а не случайному размеру;
- полный манифест читается при 100%;
- фото поддерживают текст и не превращают разворот в фотоальбом;
- нет QR, технических labels, случайных PDF-вырезок и устаревших watermark;
- карта, герб и награда различимы в печати;
- рендеры просмотрены крупно, не только контактным листом.

## Фактический checklist

- `hero_id`, имя, дети, регион, город и диапазон страниц совпадают с референсом;
- письмо и цитата принадлежат тому же герою;
- цитата дословно встречается в полном манифесте;
- манифест не сокращён и не разбит на редакционные рубрики;
- фотографии/рисунки имеют подтверждённую принадлежность;
- `region_code` соответствует `map_feature_id` и гербу;
- награда подтверждена исходником;
- неподтверждённые биофакты не опубликованы;
- официальные документы не пересказаны от имени источника;
- любое расхождение записано как `REVIEW_REQUIRED`, а не исправлено догадкой.
