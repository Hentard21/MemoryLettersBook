# Клиентский пример до 21 июля

## Цель текущего цикла

Собрать убедительный фрагмент книги, а не весь тираж: утверждённая обложка, вводный блок и только первая семья в порядке оригинального референса — Анастасия / Игорь / Волгоградская область. После неё не добавлять другие семьи без отдельного решения.

## Неподвижные правила

- Оригинальный референс задаёт порядок, семейную принадлежность материалов, медаль, герб и полный текст письма.
- Ознакомительный разворот объединяет имя, автора письма, Волгоградскую область, корректную карту региона, медаль, официальный герб, флагманский портрет и одну цитату. Отдельную страницу ради карты и медали не создавать.
- Карта: выделяется субъект `RU-VGG` / `RUVGG`, город Волгоград — только дополнительная подпись. Условная точка вместо региона запрещена.
- Следующий разворот — единый полный манифест Игоря, разделённый примерно пополам между левой и правой страницами. Текст не сокращать, не тематизировать и не реконструировать обрезанные места.
- Для большинства архивных изображений применять светлые редакционные аннотации поверх фото: белая/молочная карточка, тонкий бордовый акцент, полезная подпись. Не перекрывать лица, не превращать их в технические таблички.
- Вырезать фон только у флагманского портрета. Остальные фотографии — мягкая коррекция и при необходимости Gigapixel.
- В публичном макете нет служебных маркеров, статусов или текстов-заглушек; малое слово «ПРОТОТИП» допускается.

## Скоростной порядок работы

1. Проверить факт в `content/manifests/reference-first-20-map.json`, `content/regions/regions.json` и исходном PDF.
2. Выбрать один утверждённый путь ассета; master-файл не менять.
3. Для флагмана: Gigapixel → CutItOut → проверка маски → вставка.
4. Собрать только нужный разворот, отрендерить и визуально проверить PDF.
5. Исправлять конкретный комментарий, а не пересобирать всю книгу.

## Стоп-условие

После готового примера Анастасии остановиться. Массовые Gigapixel, генеративные и OpenRouter-задачи не запускать.
