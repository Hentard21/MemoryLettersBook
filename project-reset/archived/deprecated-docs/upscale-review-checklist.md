# Чеклист приёмки апскейла

По каждому апскейленному файлу пройдите нужный блок. Все пункты — «да». Хоть одно «нет» из красной зоны → `review/needs-redo` (или `rejected`, если апскейл в принципе не помогает).

Сравнивать всегда **рядом с оригиналом** из `assets/master-from-pdf/`.

## Фотографии (лица)

Зелёная зона (должно быть «да»):
- [ ] лицо осталось похоже на исходник — это тот же человек;
- [ ] глаза, рот, нос не искажены по форме и положению;
- [ ] форма наград, погон, элементов одежды не испорчена и не «придумана»;
- [ ] нет общей мыльности;
- [ ] нет чрезмерной пластики кожи;
- [ ] нет «пластилинового»/воскового лица.

Красные флаги (любой → `needs-redo`):
- лицо «поплыло» или стало другим человеком;
- симметрия/пропорции лица изменились;
- награды или знаки различия превратились в нечитаемую или выдуманную форму;
- глаза стали «стеклянными»/нарисованными.

## Письма

Зелёная зона:
- [ ] почерк стал **читабельнее**, чем в оригинале;
- [ ] буквы не сломались и не слиплись;
- [ ] чернила/грифель не «распались» на пиксели и не пропали;
- [ ] края листа и поля не уничтожены;
- [ ] бумага не выглядит фальшиво-гладкой (осталась фактура).

Красные флаги:
- почерк превратился в ровный печатный «шрифт»;
- тонкие штрихи исчезли или задвоились;
- фон «выбелен» так, что пропали карандашные строки.

## Детские рисунки

Зелёная зона:
- [ ] контур сохранён;
- [ ] карандашный штрих живой (видны нажим и неровности);
- [ ] цвет не ушёл и не перенасытился;
- [ ] рисунок **не** стал «нейросеточным»/цифровым.

Красные флаги:
- гладкая заливка вместо штриховки;
- «дорисованные» детали, которых не было;
- пластиковая ровность.

## Смешанные материалы

- [ ] каждый элемент (фото/письмо/рисунок) проверен по своему блоку выше;
- [ ] ни один элемент не пострадал ради другого.

## Решение

| Итог | Куда | Что дальше |
|---|---|---|
| всё в зелёной зоне | `review/approved/` | резолвер поставит в печать/веб |
| есть красный флаг | `review/needs-redo/` | прогнать заново с другими настройками |
| апскейл не помогает в принципе | `review/rejected/` | остаётся `master_from_pdf` |

Отдельно: если материал помечен `publish_blocked` (напр. письмо `hero-002_letter_01`, вопрос eq-009) — апскейл допустим, но в публикацию он всё равно не идёт до решения по принадлежности.
