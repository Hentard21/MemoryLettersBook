# Семейный разворот — единый визуальный принцип (v4)

Один язык для всех 76 семей. Не три альтернативных шаблона, а **один базовый разворот** с допустимыми вариациями по наполнению. Формат: 260 × 200 мм × 2, вылет 3 мм.

## Состав разворота (обязательный набор)

1. **Имя героя** — крупная антиква (28–40 pt).
2. **Имена детей** — авторы письма, сразу под именем героя.
3. **Регион + официальный герб** (герб 12–16 мм, только официальные файлы).
4. **Один вырезанный поясной портрет** героя или группа (семья/дети) — главный визуальный приём.
5. **Короткая биографическая справка** (только подтверждённые факты; 2–4 строки).
6. **Читаемая версия письма** — типографский набор (11–12 pt), не скан целиком.
7. **Небольшой подлинный фрагмент почерка** — полоса скана 1–3 строки, рядом с набором: документ подтверждает набор.
8. **Одна цитата** — выделенная строка письма (14–16 pt).
9. **Один дополнительный материал** — рисунок или фото (малый, на паспарту без тени).
10. **QR** на полную веб-историю (`/letters/{heroSlug}`) + подпись «полная история семьи».

## Композиционная логика

```
ЛЕВАЯ ПОЛОСА                          ПРАВАЯ ПОЛОСА
┌──────────────────────────┐  ┌──────────────────────────┐
│ ИМЯ ГЕРОЯ ←── текст может │  │ Письмо (читаемый набор)   │
│ дети ·     заходить на    │  │                           │
│ регион+герб  силуэт       │  │ ─ фрагмент почерка ─      │
│         ┌────────┐        │  │                           │
│ справка │ПОРТРЕТ-│        │  │ «Цитата»                  │
│ 2-4 стр │ВЫРЕЗКА │        │  │                           │
│         │(по пояс│        │  │ [доп. рисунок/фото]  [QR] │
└─────────┴────────┴────────┘  └──────────────────────────┘
```

- **Портрет-вырезка** стоит на молочном фоне полосы без рамки-паспарту (в отличие от документов) — человек «выходит» из страницы. Низ силуэта уходит под нижнее поле либо мягко растворяется.
- **Заголовок или короткая цитата могут частично заходить под/за силуэт** (эффект глубины), но **текст никогда не закрывает лицо** и не пересекает глаза/рот.
- Письма и рисунки — документы: тонкое паспарту (2–3 мм белого + волосяная линия), **без теней**.
- Вариации: портрет может стоять справа (зеркальная схема); группа вместо одиночного портрета; рисунок вместо второго фото. Сетка и набор элементов неизменны.

## Чего не делать

- Веб-тени, скругления, «карточки-плитки» одинакового размера.
- Случайная коллажность (повороты, скотч, наложение фото на фото).
- Полностраничные растянутые слабые фотографии.
- Служебные статусы (`pdf_reference` и т.п.) в макете.
- Логотипы партнёров на семейных разворотах.
- Текст по лицу; агрессивный кроп головы.

## Данные

Разворот собирается из пакета семьи (`content/prototypes/<hero>/content.json` + `web-package.json`): `featuredPhoto` (портрет для вырезки), `featuredQuote`, `printExcerpt` (набор письма), фрагмент почерка (кроп скана), герб региона, QR. Расшифровка — по `content/schemas/letter-transcription-schema.json`: в печать идёт только `approved_text` либо `clean_reading_version` с «…».
