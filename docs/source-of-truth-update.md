# Источник правды: обновление (2026-07-16)

## Что произошло

**Оригинальная презентация PPTX утеряна безвозвратно.** Она не будет получена. Это меняет базовое допущение всего проекта.

## Новая реальность

- **`source/reference.pdf` — единственный и окончательный мастер-источник** всего контента (текстов и изображений).
- **Все изображения** для сайта и книги — производные от этого PDF. Другого источника нет.
- Две ступени качества изображения:
  - **`master_from_pdf`** — нативный ассет, извлечённый прямо из потоков PDF (архив, потолок реального качества). Лежит в `assets/master-from-pdf/`.
  - **`derived_upscaled`** — версия после апскейла (Topaz Gigapixel). Лежит в `assets/derived-upscaled/`.
- **Для печати используются только `derived`-версии, прошедшие визуальный контроль** (см. `docs/upscale-review-checklist.md`). Не прошедшие — не идут в тираж.
- Планировать замену картинок «когда придёт PPTX» **больше нельзя**.

## Как теперь подтверждаются спорные факты

Раньше многие вопросы висели с пометкой «сверить по PPTX». Теперь спорный факт (имя, регион, город, подпись, авторство, принадлежность материала) подтверждается **только**:
1. по самому `source/reference.pdf` (если читается однозначно);
2. по согласованию с семьёй героя;
3. по материалам заказчицы (списки участников, документы).

Если ни один путь не даёт ответа — запись остаётся `REVIEW_REQUIRED`, а материал не публикуется как факт.

## Статусы качества (единый словарь)

| Статус | Значение |
|---|---|
| `master_from_pdf` | нативный ассет из PDF, неизменяемый архив |
| `derived_upscaled` | результат Gigapixel, кандидат |
| `derived_upscaled` + review `approved` | пригоден для печати/веба |
| review `needs_redo` | апскейл испортил материал — прогнать заново с другими настройками |
| review `rejected` | апскейл не помог, остаётся master |

`source_quality: "pdf_reference"` — теперь **постоянная** пометка, а не «временно до PPTX».
