# Контрольный тестовый батч Gigapixel

Цель — проверить стратегию апскейла на 6 файлах **до** прогона всей папки. Если тест проходит — настройки годятся для массового прогона; если нет — правим настройки, не потратив время на сотни файлов.

## Папка

`assets/test-batch-gigapixel/`

## 6 файлов и с какими настройками

| Файл | Тип | Режим (принцип) | На что смотреть особенно |
|---|---|---|---|
| `hero-001_photo_01_master.png` | фото, лицо (женщина) | фото + умеренное восстановление лица | лицо осталось тем же человеком |
| `hero-002_photo_04_master.png` | фото, лицо (военнослужащий в лесу) | фото, умеренно; лицо мелкое | не «дорисовать» чужие черты |
| `hero-001_letter_01_master.png` | письмо | текст/документ, без восстановления лица | читаемость почерка, фактура бумаги |
| `hero-002_letter_02_master.png` | письмо | текст/документ | буквы не «разъехались», чернила целы |
| `hero-002_drawing_01_master.png` | детский рисунок | иллюстрация/арт, мин. шумоподавление | штрих и цвет карандаша живые |
| `mixed_sample_p017_master.png` | смешанное (фото+рисунок+письмо на одном листе) | по одному, вручную | все три части читаемы; ничего не «поплыло» |

## Что делать

1. Прогнать все 6 через Gigapixel с настройками из таблицы (и `docs/gigapixel-batch-guide.md`).
2. Сохранить результат рядом или в `assets/derived-upscaled/...` с именем `..._upscaled.png`.
3. Сравнить оригинал и результат по чеклисту `docs/upscale-review-checklist.md`.

## Допустимые артефакты

- Лёгкое общее увеличение резкости.
- Небольшое уменьшение зерна/шума на фото.
- Чуть более гладкая бумага на письме — **если** почерк не пострадал.

## Недопустимые артефакты (→ `needs-redo`)

- Лицо стало похоже на **другого человека**; изменились форма глаз, носа, рта.
- «Пластилиновая»/восковая кожа, пропала фактура.
- Почерк превратился в ровный «шрифт», буквы слиплись или распались.
- Рисунок стал гладким «нейросеточным», пропал карандашный штрих.
- Ореолы, «мыло», цветные каёмки по контурам.

## После теста

- Всё хорошо → эти настройки применяем к массовому прогону (порядок — в `gigapixel-batch-guide.md`).
- Что-то из недопустимого → правим настройки для этого типа и повторяем тест только по проблемному типу.
- Сообщите агенту результат — он подхватит одобренные файлы резолвером и покажет, как они смотрятся в прототипах.
