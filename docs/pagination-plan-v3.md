# План пагинации v3

Рабочий формат: **260 × 200 мм**, горизонтальный, вылет 3 мм. Правило: **1 семья = 1 разворот** (verso + recto). Расчёт полного тома.

## Итог объёма

| Параметр | Значение |
|---|---|
| Семей | 76 |
| Семейных разворотов | 76 × 2 = **152 страницы** |
| Вводный блок | 15 страниц (стр. 1–15) |
| Основной корпус | стр. 16–167 |
| Партнёрский разворот | стр. 168–169 |
| Финальный блок | стр. 170–171 |
| Технические/пустые | стр. 172–176 |
| **ИТОГО** | **176 страниц** (кратно 16 — удобно для тетрадей и переплёта) |

176 = 11 тетрадей по 16 полос. Ближайшие альтернативы при изменении объёма: 160, 192 (тоже кратны 16/32).

## Правило разворота

Видимый разворот = левая (verso, чётная) + правая (recto, нечётная = чётная+1). Семья всегда занимает пару (2k, 2k+1), чтобы читаться как один разворот. Первый семейный разворот начинается с verso — стр. 16.

## Последовательность (recto = R/нечётная, verso = V/чётная)

| Стр. | Сторона | Содержимое |
|---:|:--:|---|
| 1 | R | Шмуцтитул: «Письма памяти» + фрагмент детского почерка |
| 2 | V | пусто (фронтиспис) |
| 3 | R | Титульный лист |
| 4 | V | Оборот титула: выходные данные, редакция, «Издание подготовлено при поддержке…» |
| 5 | R | Короткая страница-пролог / пусто (выравнивание) |
| 6–7 | V–R | **Указ Президента** (факсимиле-фрагмент + читаемый набор + пояснение) |
| 8–9 | V–R | **Вступление** «Письма, которые продолжают говорить» (текст + фрагмент письма и цитата) |
| 10–11 | V–R | **Карта России** «География памяти» |
| 12–13 | V–R | **Содержание**, разворот 1 (15 регионов) |
| 14–15 | V–R | **Содержание**, разворот 2 (16 регионов) |
| 16–167 | V–R ×76 | **Семейные развороты** (по одному на семью, шаблоны A/B/C) |
| 168–169 | V–R | **Партнёры** «Издание подготовлено при поддержке» |
| 170–171 | V–R | Финал: благодарности семьям + издательский колофон |
| 172–176 | — | технические/пустые до кратности 16 |

Номер страницы семьи = 16 + (индекс в книжном порядке) × 2. Порядок — по региону, внутри региона по имени героя (см. `content/front-matter/contents.json`).

## Альтернативное размещение партнёров

Заказчице на выбор (см. `docs/sponsors-placement-plan.md`): партнёрский разворот **после вступления** (стр. 10–11, тогда карта и содержание сдвигаются) вместо конца. В прототипе показаны оба варианта размещения; порядок влияет только на номера, не на объём.

## Замечания

- Формат и объём — рабочие, до подтверждения типографией (формат полосы, поля, переплёт, толщина корешка от бумаги).
- Ширина корешка не фиксируется — зависит от бумаги и итогового объёма.
- Расширенные семьи (2 разворота) — редкое исключение; каждое такое исключение сдвигает нумерацию и меняет итог на +2.
