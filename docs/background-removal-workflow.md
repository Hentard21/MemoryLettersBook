# Удаление фона: флагманские портреты

Этот поток применяется только к одному флагманскому снимку героя для ознакомительного разворота с именем, регионом и картой. Он не предназначен для массовой обработки семейных фото, рисунков или писем.

## Инструмент

- Локальная копия: `C:\Users\MarkII\Книга Письма Памяти\tools\cut-it-out`
- Запуск в PowerShell:

  ```powershell
  Set-Location 'C:\Users\MarkII\Книга Письма Памяти\tools\cut-it-out'
  npm run dev -- --host 127.0.0.1
  ```

- Открыть адрес, который выведет Vite (обычно `http://127.0.0.1:5173`). CutItOut выполняет обработку в браузере; не загружать туда материалы для других целей.

## Быстрый рабочий цикл

1. Открыть CutItOut.
2. Загрузить уже улучшенный флагманский портрет.
3. Проверить край маски: волосы, кисти, оружие, ремни, форму, награды, экипировку и любые предметы в руках.
4. При необходимости поправить маску кистью: `Erase` убирает лишнее, `Restore` возвращает утраченные части.
5. Экспортировать прозрачный PNG.
6. Переименовать файл с суффиксом `_nobg`.
7. Сохранить результат в одну из папок:
   - `assets/background-removed/approved/` — край маски чистый и фигура готова для макета;
   - `assets/background-removed/needs-fix/` — результат годится как быстрый временный слой, но требует ручной доводки;
   - `assets/background-removed/rejected/` — лицо, руки, форма, награды или предметы повреждены.

## Правило скорости

Сначала попробовать автоматический результат и проверить его на светлом фоне макета. Не тратить время на вырезание всех фотографий: вырезка оправдана только тогда, когда именно она делает ознакомительный разворот компактнее. Исходники и улучшенные master-файлы не перезаписывать.
