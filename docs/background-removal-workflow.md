# CutItOut: только подтверждённые флагманы

CutItOut используется исключительно для главного изображения ознакомительной страницы семьи. Архивные фотографии через него автоматически не проходят.

## Порядок

1. Проверить `assets/families/family-processing-plan.json` и очередь `assets/processed-flagships/flagship-processing-queue.json`.
2. Если стоит `needs_gigapixel: true`, сначала получить ручной результат Gigapixel.
3. Открыть локальный CutItOut:

   ```powershell
   Set-Location '..\tools\cut-it-out'
   npm run dev -- --host 127.0.0.1
   ```

4. Загрузить улучшенный флагман.
5. Проверить волосы, руки, оружие, ремни, форму, нашивки, награды, экипировку и предметы в руках.
6. При необходимости поправить маску кистями `Erase` и `Restore`.
7. Экспортировать прозрачный PNG с суффиксом `_nobg`.
8. Сохранить его в `assets/processed-flagships/<hero_id>/`.
9. Обновить `assets/processed-flagships/flagship-cutout-log.json`.

Для быстрой первичной маски доступен `scripts/batch_cutitout.py`; точная команда и ограничения описаны в `docs/CUTITOUT_AUTOMATION.md`. Автоматическая вырезка считается только кандидатом `needs_manual_mask_review`, а не утверждённым результатом.

## Критерии

- лицо и узнаваемость не меняются;
- одежда и предметы не заменяются;
- края волос и формы проверяются на светлом и тёмном фоне;
- кадрирование примерно по пояс применяется только при подтверждённой композиционной необходимости;
- master-файл не перезаписывается;
- сомнительный результат получает статус `needs-fix`, а не `approved`.
