# Полное черновое издание

## Текст

Для чернового издания в вёрстку подставляется подготовленный `*_print.txt`, даже если соседний JSON ещё имеет `approved_for_print: false`.

Это не означает утверждение текста для типографии:

- физическая рукопись остаётся рядом с расшифровкой;
- `[неразборчиво]`, обрезанные места и зафиксированные сомнения не заменяются догадкой;
- статус проверки сохраняется в данных, но не превращается в заметную техническую надпись на публичной странице;
- перед финальной печатью человек сверяет текст с рукописью и подтверждает исправления.

## Семьи на уточнении

В черновом издании пять семей временно собираются в конце отдельным блоком семейного архива:

- `hero-006`, `hero-058`, `hero-065`, `hero-069` — физическая рукопись пока не зарегистрирована;
- `hero-030` — подпись на назначенном письме конфликтует с составом семьи в манифесте.

Для этих страниц:

- используются только подтверждённые фотографии, рисунки, имя, регион и другие зарегистрированные материалы;
- письмо не сочиняется и не приписывается семье;
- конфликтный скан `hero-030` хранится для показа заказчику, но не используется как подтверждённый основной текст;
- применяется спокойная композиция семейного архива по расширенному шаблону Евгения;
- это временное изменение последовательности только для черновика.

После ответа заказчика семья возвращается на своё место `reference_order`, а материал связывается только с подтверждённой семьёй.

Машиночитаемый список: `content/manifests/draft-deferred-families.json`.
