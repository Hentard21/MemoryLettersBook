# Карта России и гербы регионов

Как показывать географию семей — во вступлении, на карточках героев и на разворотах. Финальную карту и гербы **пока не создаём** — здесь структура данных и правила.

## Карта России

- **Общая карта РФ** с выделением регионов, откуда семьи-участники. Стиль — сдержанный, в палитре направления A: светлая база, регионы-участники залиты приглушённым синим (`--blue`), выделенный/акцентный — приглушённым красным. Без пёстрой политической раскраски (в исходном PDF карта именно такая пёстрая — заменяем).
- **Вступление:** одна общая карта-разворот со всеми регионами-участниками и их числом.
- **Карточка героя / разворот:** мини-карта или просто маркер конкретного региона (не вся детальная карта — только «где это»).
- Технически карту делать **вектором (SVG)**, а не растровым апскейлом из PDF: она масштабируется, перекрашивается под тему и одинаково хороша в печати и вебе. Растровые карты из PDF (`title/*map*`) — только временная заглушка, в тираж не идут.

## Подписи регионов

- Название региона — **дословно из данных** (`region_raw`), с последующей нормализацией названий (в исходнике есть артефакты парсинга — см. ниже).
- Формат подписи единый: «Регион · Город» (напр. «Волгоградская область · г. Волгоград»).

## Гербы регионов

- Показывать **небольшой герб региона** на карточке героя и на развороте (в титульной зоне семьи).
- Источник гербов: **официальные геральдические изображения**, не апскейл мутных версий из PDF. Гербы в PDF (`title/*award*`, гербы на титулах) — низкого качества, для тиража непригодны.
- Хранить как отдельные векторные/качественные файлы по региону (переиспользуются между семьями одного региона).
- **Награды** (ордена на титулах) — это НЕ гербы; их атрибуция FACT_LOCKED, не публиковать название награды без подтверждения.

## Структура данных (для будущей карты)

`content/entities/regions.json` (будущий):

```json
{
  "region_id": "volgogradskaya-oblast",
  "name_display": "Волгоградская область",
  "name_raw_variants": ["Волгоградская область"],
  "federal_subject_code": null,
  "emblem_asset": null,
  "map_highlight_id": "RU-VGG",
  "hero_ids": ["hero-001"],
  "family_count": 3
}
```

- `map_highlight_id` — код субъекта для подсветки на SVG-карте (стандарт ISO 3166-2:RU).
- `emblem_asset` — путь к качественному гербу (заполняется позже).
- `hero_ids` / `family_count` — связь с семьями и число для карты вступления.

## Использование

- **Вступление:** общая карта + список регионов с числом семей.
- **Карточка героя (сайт):** мини-карта/маркер + герб + подпись региона.
- **Разворот (книга):** герб + маркер региона в титульной зоне семьи (композиции A/B/C из `print-structure-v2.md`).

## Что НЕ делаем сейчас

Не генерируем финальную карту, не рисуем финальные гербы, не апскейлим карты/гербы из PDF. Только структура и правила.
