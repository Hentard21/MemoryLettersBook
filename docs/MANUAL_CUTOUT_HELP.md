# Ручная подготовка титульных флагманов

С 21 июля 2026 года действует новое правило владельца: **каждый титульный
флагман проходит ручную проверку**. Автоматическая маска CutItOut сама по себе
не считается финальным результатом.

## Уже закрытые материалы

- `hero-001` — утверждённый титульный флагман Анастасии;
- `hero-014` — утверждённый визуальный ориентир размещения Евгения;
- 13 подготовленных владельцем белофоновых изображений обработаны локальным
  CutItOut и допущены в черновой макет после проверки на молочном и тёмно-синем
  фоне: `hero-003`, `hero-011`, `hero-015`, `hero-024`, `hero-029`, `hero-036`,
  `hero-044`, `hero-047`, `hero-051`, `hero-059`, `hero-061`, `hero-066`,
  `hero-071`.

Их исходники в `assets/manual-cutout-help/` не перезаписаны. Прозрачные
производные лежат в `assets/processed-flagships/<hero_id>/` и заканчиваются на
`_manual_nobg.png`. Техническая проверка зафиксирована в
`assets/processed-flagships/manual-owner-cutout-validation.json`, контактный
лист — в
`workspace/reports/manual-flagship-cutouts/manual-cutout-contact-sheet.png`.

Статус этих 13 файлов: `ready_for_draft_layout`; окончательное подтверждение
владельца остаётся отдельным шагом.

`assets/manual-cutout-help-next/manifest.json`.

Проверка пакета:

```powershell
python scripts\build_next_title_cutout_package.py --verify-existing
```

## Правило обработки

1. Работать с лучшим доступным исходником, не перезаписывая master.
2. Сохранять лица, волосы, руки, оружие, ремни, форму, нашивки, награды и все
   предметы в руках. Связанные группы не разделять.
3. Фон удалять только у подтверждённых титульных флагманов. Архивные фотографии
   через CutItOut массово не проходят.
4. Результат сохранять отдельным PNG с прозрачностью и суффиксом `_nobg`.
5. Проверять края на молочном и тёмно-синем фоне.
6. На титульной странице фигуру компоновать вручную по ориентиру Евгения:
   крупно, с опорой на нижний край, примерно по пояс. Полнофигурный исходник
   обрезается только снизу; лицо и важные предметы не перекрываются.
7. Реальный effective DPI продолжает фиксироваться честно. Для материалов, где
   улучшить исходник больше невозможно, используется явная пометка
   `OWNER_ACCEPTED_SOURCE_LIMIT`; детали не выдумываются и фиктивный DPI не
   указывается.

## Локальный CutItOut

Скрипт сам запускает локальный интерфейс и Chromium. Сухой запуск обязателен:

```powershell
python scripts\batch_cutitout.py `
  --source assets\production-ready\flagship\hero-XXX\source.png `
  --hero-id hero-XXX `
  --output assets\processed-flagships\hero-XXX\hero-XXX_manual_nobg.png
```

Фактический запуск — та же команда с `--apply`. Старый PNG без `--force` не
перезаписывается.
