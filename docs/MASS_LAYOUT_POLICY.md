# Политика массовой вёрстки

## Базовое правило

Одна семья — один основной разворот. Если полный документальный комплект не помещается читаемо, автоматически добавляется один разворот-продолжение.

Это правило защищает четыре неизменяемых требования:

- весь оригинальный контент сохраняется;
- каждая рукопись физически присутствует;
- у каждой рукописи есть отдельная полная расшифровка;
- фотографии и текст не уменьшаются до нечитаемого размера.

## Когда разрешено продолжение

Продолжение создаётся только при объективном переполнении после применения утверждённых шаблонов. Основания:

- несколько самостоятельных рукописей;
- длинная полная расшифровка;
- более четырёх значимых фотографий или рисунков, которые нельзя исключить по референсу;
- документальные материалы, требующие различимого физического размера.

Продолжение не используется для декоративного увеличения объёма и не меняет порядок семей.

## Что запрещено

- сокращать, пересказывать или дробить полный текст на редакционные тезисы;
- уменьшать основной текст ниже утверждённого печатного минимума;
- превращать фотографии в неразличимые миниатюры;
- убирать рукопись после появления расшифровки;
- переносить остаток семьи после материалов следующего героя;
- дублировать флагман или архивные фотографии без документальной причины.

## Логика генератора

1. Генератор сначала пытается собрать основной разворот.
2. Preflight проверяет переполнение текста, минимальный размер изображений, корешок и безопасные поля.
3. Если комплект не помещается, создаётся один разворот-продолжение непосредственно следом.
4. Если не помещается и после этого, семейный блок получает `MANUAL_LAYOUT_REQUIRED`; контент автоматически не отбрасывается.
