# Правила компоновки фотографий (эталон V13)

Назначение: единая, повторяемая логика размещения снимков на семейном развороте,
пригодная для алгоритмической вёрстки. Приоритеты — подлинность, читаемость,
целостность лиц. Расшифровка письма всегда защищена и не приносится в жертву фото.

## Жёсткие правила
1. **Лица не обрезаются.** Ни портрет, ни групповое фото не кадрируются так, чтобы срезать лицо или голову.
2. **Кадр по натуральному соотношению.** Фото показывается целиком: `object-fit:contain`, либо рамка задаётся ровно под соотношение снимка. Обрезка `cover` допускается только когда соотношение рамки уже совпадает с соотношением снимка (кадр не теряется).
3. **Лучше уменьшить, чем криво кадрировать.** Если снимок не помещается красиво — уменьшаем его, а не режем. Маленькое, но целое фото предпочтительнее большого, но обрезанного.
4. **Расшифровка неприкосновенна.** Сначала выделяется зона расшифровки (защищённая), фото занимают оставшееся пространство.
5. **Материалы только своей семьи.** Фото другой семьи использовать нельзя.

## Классификация снимка
Перед размещением определяется ориентация по соотношению `w/h`:
- **портрет / вертикаль** — `w/h < 0.9`;
- **квадрат** — `0.9 ≤ w/h ≤ 1.2`;
- **пейзаж / горизонталь** — `w/h > 1.2`.

## Роли и приоритет
1. **Ведущий контекстный снимок** (герой / семья с героем) — самый крупный из архивных.
2. **Второстепенные фото** — меньше ведущего.
3. **Детский рисунок** — акцент; на плотной странице может быть уменьшен до небольшого размера, но не искажается и не переводится в цифровую иллюстрацию.

## Алгоритм раскладки (повторяемый)
1. Зарезервировать зону расшифровки (≈ половина полосы; на V13 — правый блок, `width ≈ 120 мм`).
2. Оставшуюся зону отдать под фото-стек.
3. Внутри фото-зоны выбрать **общий базовый размер**:
   - при раскладке **в ряд** — общая высота, ширина каждого кадра = высота × (w/h). Вертикальные получаются узкими, горизонтальные широкими, все стоят на одной линии.
   - при раскладке **в столбик** — общая ширина, высота = ширина ÷ (w/h).
4. Разместить кадры по приоритету: ведущий — крупнее, далее второстепенные, рисунок — акцентом.
5. **Проверка вместимости:** если сумма размеров + зазоры превышает зону при читаемом масштабе — уменьшить общий базовый размер. Если после уменьшения снимки становятся мельче печатного минимума — добавить один разворот-продолжение (по правилу объёма семейного блока), а не резать кадр.
6. Единые отступы между кадрами (на V13 — 5–6 мм) и единые подписи (`Семейный архив` и т. п.).

## Границы масштаба
- Минимальная ширина осмысленного архивного фото на полосе — ориентировочно **34 мм**; ниже — только детский рисунок как мелкий акцент.
- Ведущий снимок не увеличивается сверх исходного качества: при исходнике ~580 px по длинной стороне не выводить крупнее ~90 мм (иначе видна мягкость апскейла).

## Инстанс hero-001 (V13)
Три вертикальных материала (групповое фото, портрет ребёнка, рисунок) + расшифровка.
Раскладка: расшифровка справа (защищена, `120 мм`); слева столбик из двух вертикальных
фото по общей ширине `51 мм` (целиком, без обрезки лиц); детский рисунок — акцент `42 мм`
между колонкой фото и карточкой расшифровки. Подлинная рукопись — растворённый фон.
