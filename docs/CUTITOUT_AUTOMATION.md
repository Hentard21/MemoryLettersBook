# Автоматизация CutItOut

`scripts/batch_cutitout.py` запускает неизменённый локальный CutItOut через его Vite-интерфейс и Playwright. Скрипт предназначен только для подтверждённых флагманских изображений.

Без `--apply` выполняется только безопасная проверка задания:

```powershell
python scripts\batch_cutitout.py --source assets\production-ready\flagship\hero-003\hero-003_p020_image146_upscaled_2x.jpg --hero-id hero-003
```

Контрольный запуск одного изображения:

```powershell
python scripts\batch_cutitout.py --source assets\production-ready\flagship\hero-003\hero-003_p020_image146_upscaled_2x.jpg --hero-id hero-003 --apply
```

Запуск очереди по умолчанию ограничен одним изображением. Увеличивать лимит следует только после визуальной проверки предыдущих результатов:

```powershell
python scripts\batch_cutitout.py --queue assets\processed-flagships\flagship-processing-queue.json --limit 1 --apply
```

## Ограничения и проверки

- исходник должен находиться в `assets/production-ready/flagship/<hero_id>/` или `assets/families/<hero_id>/flagship/`;
- PNG записывается только в `assets/processed-flagships/<hero_id>/`;
- существующий результат не перезаписывается без `--force`;
- исходный размер изображения сохраняется;
- после экспорта автоматически проверяются формат PNG, размеры и наличие реальной прозрачности;
- успешная автоматическая вырезка получает технический статус `needs_manual_mask_review`: волосы, руки, оружие, ремни, форма и предметы всё равно проверяются визуально;
- скрипт не изменяет семейные манифесты и не применяет CutItOut к архивным фотографиям;
- для работы требуется локальный Playwright из `.tools/playwright/` и установленный CutItOut в соседней с проектом папке `tools/cut-it-out/`.

## Proof-of-concept: hero-003

Контрольный запуск выполнен для `assets/production-ready/flagship/hero-003/hero-003_p020_image146_upscaled_2x.jpg`.

- результат: `assets/processed-flagships/hero-003/hero-003_p020_image146_nobg.png`;
- исходный и выходной размер: `580 × 940 px`;
- alpha-канал: присутствует, диапазон `0…254`;
- прозрачных или полупрозрачных пикселей с alpha ниже 250: `385626`;
- итоговый статус: `needs-fix`.

Модель сохранила фигуру, форму, руки и оружие, однако автоматически захватила отдельные фоновые предметы и оставила цветные артефакты по нижнему и правому краю. PNG пригоден как доказательство работы конвейера, но перед книжной вёрсткой требует ручной правки маски в CutItOut.

## Партия подтверждённых флагманов

После proof-of-concept выполнена очередь из 58 подтверждённых флагманов. Девять записей `REVIEW_REQUIRED` автоматически пропущены.

- завершено: **58 из 58**;
- технически валидных PNG с alpha: **58**;
- автоматически утверждено: **0**;
- статус всех результатов: `needs_manual_mask_review` / `needs-fix`;
- время пакетного запуска в одном браузере: около 6 минут 56 секунд;
- индекс: `assets/processed-flagships/cutout-validation.json`;
- светлые/тёмные контактные листы: `project-reset/reports/flagship-cutouts/`.

Контактные листы подтверждают, что большинство фигур пригодны как рабочие черновики, но у части кадров остаются цветные ореолы, фрагменты фона или связанные предметы. Эти PNG нельзя механически считать финальными.
