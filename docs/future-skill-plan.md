# План будущего project skill `letters-memory-book`

Skill пока не создаётся. Этот документ описывает его будущую область ответственности после ручного утверждения reset-регламента.

## Назначение

Будущий skill должен помогать агентам последовательно собирать книгу по оригинальному референсу, не изменяя факты, порядок и принадлежность материалов. Он должен ускорять повторяемые проверки и команды, но не принимать за владельца содержательные решения.

## Обязательные источники skill

- `docs/PROJECT_RULES_RESET.md` — главный регламент;
- `docs/SEQUENTIAL_WORKFLOW.md` — порядок этапов и стоп-условия;
- `docs/REFERENCE_LOCK.md` — запрет перестановок и подмен;
- подтверждённый манифест порядка семей;
- манифесты отдельных семей;
- индекс рукописей и расшифровок;
- план обработки флагманских и архивных материалов;
- утверждённые команды рендера и проверки.

## Правила, которые skill должен применять

### Последовательность по референсу

- определять только следующую незавершённую семью;
- запрещать переход к следующей семье до проверки текущей;
- сверять порядок с эталонным манифестом;
- останавливать работу при неоднозначности вместо догадки.

### Флагманские материалы

- выбирать только подтверждённый `flagship_asset`;
- разрешать Gigapixel, аккуратное кадрирование и CutItOut;
- сохранять черты лица, одежду, форму, награды, нашивки, экипировку и предметы;
- ориентироваться на роль страницы Анастасии из V12, не копируя её сведения;
- вести журнал исходника, результата и статуса проверки.

### Семейный архив

- сохранять фон по умолчанию;
- использовать мягкое улучшение и Gigapixel;
- не отправлять все фотографии на удаление фона;
- не допускать агрессивной генеративной переработки;
- предотвращать повторное использование одного снимка внутри семейного блока без явного разрешения.

### Рукописи и расшифровки

- проверять физическое наличие каждой рукописи;
- проверять наличие отдельной связанной расшифровки;
- сохранять полный текст и авторскую форму;
- не восстанавливать неразборчивые места по смыслу;
- использовать `missing` и `REVIEW_REQUIRED` для пробелов;
- запрещать замену рукописи одной стилизованной типографикой.

### Фактическая проверка

Skill должен проверять:

- героя и автора письма;
- родственную связь;
- порядок семьи;
- принадлежность каждого изображения;
- регион и город;
- карту и выделенный субъект;
- официальный герб;
- награду;
- источник цитаты;
- соответствие рукописи расшифровке.

Ни OCR, ни имя файла, ни дизайн-макет не считаются достаточным подтверждением.

## Команды, которые стоит включить

- нормализация структуры папок семей;
- экспорт утверждённых файлов в очередь Gigapixel;
- построение очереди флагманов;
- проверка JSON-манифестов;
- проверка индекса рукописей и расшифровок;
- проверка повторов изображений в семейном блоке;
- рендер текущего разворота;
- автоматическое создание не более одного разворота-продолжения при подтверждённом переполнении;
- визуальная проверка корешка, полей и читаемости;
- сборка отчёта перед переходом к следующей семье.

Точные команды включаются только после проверки существующих скриптов и среды Windows/PowerShell. Skill не должен выдумывать команды или пути.

## Визуальный checklist

- [ ] Утверждённая обложка не изменена.
- [ ] Флагман читается как главный образ героя.
- [ ] Нет важных деталей в корешке или за пределами печатной зоны.
- [ ] Лица и награды не перекрыты текстом.
- [ ] Фотографии не дублируются без причины.
- [ ] Архивные фотографии сохраняют документальность.
- [ ] Физическая рукопись видна как отдельный материал.
- [ ] Полная расшифровка читаема при масштабе 100%.
- [ ] Рисунки сохраняют детский штрих.
- [ ] Нет служебных надписей в публичном макете, кроме разрешённого ненавязчивого обозначения прототипа.

## Фактический checklist

- [ ] Семья находится на правильном месте.
- [ ] Герой и ребёнок указаны верно.
- [ ] Автор письма подтверждён.
- [ ] Все материалы принадлежат этой семье.
- [ ] Регион, город, герб, карта и награда проверены.
- [ ] Цитата дословно взята из связанного письма.
- [ ] Полный текст не сокращён и не переписан.
- [ ] Каждой рукописи соответствует отдельная расшифровка.
- [ ] Все неопределённости отмечены `REVIEW_REQUIRED` или `missing`.

## Ограничения будущего skill

Skill не должен:

- менять утверждённую обложку;
- переставлять семьи;
- создавать биографии, подписи или цитаты;
- редактировать оригинальный текст;
- смешивать материалы семей;
- автоматически применять CutItOut ко всему архиву;
- запускать массовую обработку без подтверждённой очереди;
- продолжать после стоп-условия;
- считать себя источником фактов.

## Условие создания skill

Skill можно создавать только после того, как владелец:

1. утвердит reset-регламент;
2. подтвердит порядок семей;
3. утвердит визуальный шаблон;
4. проверит структуру манифестов;
5. утвердит команды рендера и проверки.
