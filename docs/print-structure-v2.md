## Базовая модель: 1 семья = 1 разворот

На одном горизонтальном развороте (две полосы) для одной семьи размещается:

- имя героя (крупно);
- автор(ы) письма (дети);
- регион;
- герб региона (небольшой);
- маленькая карта/маркер региона;
- 1 главное фото;
- 1 письмо или его фрагмент (скан);
- короткая расшифровка / цитата из письма;
- 1–2 дополнительных материала по месту (фото или детский рисунок).

**Расширенный случай (редко):** для семей с большим числом сильных материалов — 2 разворота. Это исключение, а не правило; решает редакция.

## Три композиции одного разворота

### Композиция A — «Титул + документ» (базовая, спокойная)
- **Левая полоса:** имя героя, автор письма, регион + герб + маркер на мини-карте, 1 главное фото (крупно).
- **Правая полоса:** скан письма (крупно) + узкая колонка расшифровки/цитаты снизу или сбоку.
- Подходит большинству семей; читается «портрет → его/её письмо».

### Композиция B — «Галерея + голос»
- **Левая полоса:** сетка из 2–3 материалов (фото + детский рисунок), имя и регион сверху.
- **Правая полоса:** одно письмо + цитата.
- Для семей, где сильны фотографии/рисунки, а письмо одно.

### Композиция C — «Письмо-герой»
- **Разворот целиком строится вокруг письма:** скан крупно на правой полосе, слева — имя, регион, герб, маркер, 1 фото средним планом и большая выразительная цитата.
- Для особенно сильных писем; максимум воздуха, минимум элементов.

Во всех композициях: единый горизонтальный формат (рабочий 280×210 мм, до техтребований типографии), паспарту у сканов/фото, тонкая триколорная линия как единственный флаговый мотив, цитата — дословная (FACT_LOCKED).

## Что берётся из общей базы

- имя/регион/город/авторы — `content/entities/heroes.pdf-stage.json`;
- изображения — `preferred_print_asset` (upscaled approved, иначе master) по `docs/asset-resolution-policy.md`;
- расшифровки — из пакетов героев (только `approved` reader-версия или дипломатическая; см. `editorial-workflow.md`);
- герб/маркер — из `docs/map-and-emblems-plan.md`.

## Масштабируемость

Разворот собирается из данных по шаблону композиции (A/B/C), а не верстается вручную для каждой семьи. Раскладку хранить как данные (поле `spread_template` у героя — будущий этап), чтобы 76 разворотов генерировались единообразно и правились централизованно.

## Чего на этом этапе НЕ делаем

Полную вёрстку всех 76 разворотов, финальный формат (ждём типографию), IDML. Сейчас — только модель и три композиции.
