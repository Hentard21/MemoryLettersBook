# book-project — «ПИСЬМА ПАМЯТИ», Том I

Единая контентная база мемориального издания: печатная книга + веб-версия.

**Начни отсюда:** [docs/PROJECT_BRIEF.md](docs/PROJECT_BRIEF.md) — что это и зачем. Для ИИ-агентов: [docs/AI_HANDOFF.md](docs/AI_HANDOFF.md) — обязательное чтение перед работой.

```
source/     — исходники (НЕ ИЗМЕНЯТЬ): reference.pdf (эталон, 255 стр.), горизонтальный черновик, стилевая презентация
workspace/  — извлечённые данные и отчёты (перегенерируемые)
content/    — структурированный контент: сущности, разделы, манифесты
design/     — стилевые ориентиры
docs/       — памятки и планы (веб, печать, приём PPTX, модель контента, архетипы)
scripts/    — конвейер (Python: pdfplumber, pypdf, pypdfium2)
output/     — будущие сборки (пусто на pdf-этапе)
```

Пересборка данных: `python scripts/01_analyze_pdf.py && python scripts/02_build_manifest.py`
