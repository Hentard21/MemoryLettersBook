# V29 — одноколоночные приветствия

V29 — отдельный клиентский вариант вступления поверх утверждённой полной
сборки V28. В нём изменены только пять авторских обращений:

- Л. В. Шумилов;
- А. А. Макарычев;
- А. Ю. Белянинов;
- С. К. Смирнова;
- А. А. Тенгебаева.

Принцип: портрет и должность собраны компактным блоком в верхнем внешнем углу,
а полный текст обращения идёт одной непрерывной колонкой. Реальные подписи
оставлены только у Шумилова и Макарычева, поскольку для остальных подтверждённые
файлы подписей отсутствуют.

Хроника, карта, указ, содержание, страница будущей фотохроники Адины Арыковны,
все 74 семьи и финал не переразмечались. Семейные развороты и финал повторно
используются из `output-v28-map-restored`.

## Сборка

```powershell
python scripts/build_v29_single_column_welcome.py
```

Результаты:

- `output/pdf/PRINT_V29_SINGLE_COLUMN_WELCOME_CLIENT.pdf` — компактный
  клиентский просмотр;
- `output-v29-single-column-welcome/PRINT_V29_SINGLE_COLUMN_WELCOME_SPREADS.pdf`
  — тяжёлый локальный просмотрочный PDF без растрирования;
- `v29-validation.json` — контроль пагинации, DOM и SHA-256 повторно
  использованных семейных разворотов;
- `welcome-contact-sheet.png` — четыре разворота для быстрой визуальной сверки.

Клиентский PDF не является типографским мастер-файлом.
