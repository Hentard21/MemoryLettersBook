# V20 — утверждённый Design Lock

Главный файл: `PRINT_V20_CLIENT_TEMPLATE_APPROVAL.pdf`.

Статус с 21 июля 2026 года: визуальная концепция, обложка, типографика и композиционные принципы `standard`/`extended` утверждены перед массовой вёрсткой. Изменения допускаются только при блокирующей технической причине печатного preflight и не должны создавать новый художественный вариант.

Что проверяется заказчиком:

- вступительный блок и обновлённая страница организаторов/партнёров;
- стандартный семейный шаблон по образцу Анастасии;
- расширенный семейный шаблон по образцу Евгения;
- допустимость одного разворота-продолжения, если полный комплект не помещается читаемо.

Изменения относительно предыдущего кандидата:

- организаторы и будущие партнёры собраны в более плотную и пропорциональную композицию;
- подключена исправленная владельцем фигура Анастасии с дорисованным плечом;
- подключена белофоновая фотография Евгения с детьми;
- исправлено кадрирование архивной фотографии в основном развороте Евгения.
- флагман Евгения увеличен и опущен к нижней плоскости страницы; цитатный модуль сдвинут влево и частично перекрывает фотографию;
- расшифровки двух рукописей Евгения увеличены и плотнее используют бумажные модули.
- на странице 12 хроники фотография диалога взрослого и ребёнка уменьшена, два события разведены по вертикали и получили самостоятельные светлые карточки с интегрированными подписями по приёму страницы 11.

Папка `renders/` содержит пять контрольных изображений. Композиционная система заморожена; фактические данные каждой семьи всё равно берутся только из референса и манифестов.

Промежуточные PDF V14–V19 намеренно не хранятся в Git. Воспроизводимая сборка финального файла:

```powershell
node scripts\build_combined_v18.mjs
node scripts\render_print_prototype.mjs --input design\prototypes\print-v12\interior-combined-v18.html --output design\prototypes\print-v12\PRINT_V18_REFINED_CLIENT_OVERVIEW.pdf
node scripts\render_print_prototype.mjs --input design\prototypes\print-v18\family-hero-014-two-spread.html --output design\prototypes\print-v18\PRINT_V18_HERO_014_TWO_SPREAD_TEST.pdf
python scripts\build_template_freeze_pdf.py
```
