# Куда положить арт обложки

Созданный арт (фон передней обложки) положите сюда с именем:

```
design/cover-v1/artwork/cover-art.png
```

Рамка `../layout/cover-front.html` подхватит его автоматически как полнополосный фон; название, подзаголовок, том и организация набираются ПОВЕРХ отдельным текстовым слоем (их в арт не вшивать).

## Технические требования к арту

| Параметр | Значение |
|---|---|
| Полный размер с вылетом | **266 × 206 мм** (обрезной 260 × 200, вылет 3 мм со всех сторон) |
| Разрешение для печати | 300 dpi → **3142 × 2433 px** (минимум 2600 × 2014 px) |
| Формат | PNG (или TIFF → положить рядом, конвертируем) |
| Цвет | RGB (цветоделение — на препресс-этапе) |

## Композиционные зоны (важно при создании арта)

- **Безопасная зона текста:** слева, от ~20 мм до ~130 мм по ширине, сверху 28–95 мм — здесь встанет название «ПИСЬМА ПАМЯТИ» + подзаголовок. Арт в этой зоне должен быть спокойным (без мелких контрастных деталей).
- **Нижняя левая полоса** (~20 мм от низа) — строка организации/года.
- Не размещать ключевые детали арта ближе 6 мм к краям (обрежется/уйдёт в скругление обложки).
- Палитра арта — молочный / глубокий синий / приглушённый бордовый, допустимы фрагменты детского почерка; без сгенерированных лиц и вымышленных документальных сцен.
