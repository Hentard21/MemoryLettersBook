# Стилевые заметки (по source/style-reference-presentation.pdf и horizontal-draft.pdf)

Не финальный дизайн — только зафиксированные ориентиры заказчика.

- **Характер:** современный, чистый, патриотичный; много воздуха, светлый фон.
- **Цвета:** триколор России вшит на уровне палитры — белый фон, синий (насыщенный, основной акцент), красный (второй акцент, выделение слов в заголовках). В horizontal-draft — синие угловые клинья/рамки по краям полосы.
- **Типографика ориентира:** крупные ВЕРХНИМ РЕГИСТРОМ заголовки с двухцветным выделением слов (синий/красный); подписи-«бейджи» в капсулах; в книге — классическая антиква для титулов («ПИСЬМА ПАМЯТИ») + гротеск для служебных подписей.
- **Паттерн обращения (из horizontal-draft):** текст письма курсивом слева (~2/3 ширины), портрет подписанта справа в белой рамке-паспарту, автограф поверх текста.
- **Фото:** белые рамки-паспарту с лёгкой тенью (см. коллажи в reference.pdf) — приём можно сохранить в обоих продуктах.
- Логотипы: АНО «Центр поддержки детей» (сине-красные параллелограммы) — использовать только оригинальные файлы, не перерисовывать.

Финальную дизайн-систему (палитра в HEX, шрифтовые пары, сетки) строить отдельным этапом на базе этих ориентиров + PPTX.
